# Level 2 · Assisted

**AI in every pod's daily work.** AI drafts; engineers write, integrate and release by hand.

[← L1](level-1-foundation.md) · [All levels](README.md) · [L3 →](level-3-orchestrated.md)

## What changes at this level

- Coding assistants and an AI first-pass review in every pod
- Context library for every product: standards, prompts, skills
- Spec and ADR templates; AI drafts tests with the code
- Champions run the waves; training for everyone

## Exit criteria

A team reaches Level 2 when every criterion below is met with evidence.

| Dimension | Criterion | How to get there | Owner |
|---|---|---|---|
| Governance | Tool and model approvals in days through one board | Stand up the AI review board with a 5-day approval target | Security + architecture |
| Lifecycle | AI code review in the review checklist | Add AI code review to the review checklist and train reviewers | Staff engineers |
| Lifecycle | Specs from the template for work over 3 days | Require a template spec for work over 3 days; AI drafts, product approves | Product + architects |
| Platform | Context library with instructions, standards, prompts and templates | Publish repo instructions, coding standards, prompts and spec and ADR templates | AI Enablement + architects |
| Platform | A context library for every product | Build a context library for every product | Product champions |
| People | A champion in every pod; all engineers trained | Name a champion in every pod and run essentials training in the waves | AI Enablement + champions |
| Measurement | Escaped defects at or below the baseline | Track escaped defects against the baseline and fix rework hot spots | Engineering excellence + QE |
| Measurement | Rework on AI-assisted PRs at or below baseline | Track rework on AI-assisted PRs per pod and fix hot spots | Engineering excellence |
| Partners | Partner teams onboarded with their own champions | Include partner teams in the rollout waves, each with a champion | Vendor management + champions |

## First steps

- Run the pilot with AI first-pass review and AI-drafted tests
- Publish spec and ADR templates the agents read
- Build a context library for every product, then run the waves

## Risks to watch

- Review load rises as AI writes more code
- Rework hidden inside faster PRs
- Uneven adoption across pods

## Central assets

**Documents**

- Spec template (intent, acceptance criteria, non-functional needs, risk tier)
- ADR template
- PR template with AI disclosure
- AI code review checklist
- Repo instructions standard
- Skill authoring guide

**Shared skills**

- Coding standards per stack
- Test writing
- Spec drafting
- PR description
- First-pass code review

**Training**

- Champions: Practitioner (12 h + practicum)
- All engineers: AI-DLC essentials (4 h)

## Habits that make the move stick (level 1 → 2)

- Publish pilot wins and numbers every week
- Licences and gateway capacity ready before wave 1
- Include offshore and partner teams from the first wave
